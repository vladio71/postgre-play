# 31 · бос 2: когорти

**Патерн:** join + group by + `date_trunc` + умовний `count`. Когорта = місяць реєстрації. "Утримано" = логінився хоч раз **у наступному місяці** після реєстрації.

```
users              logins (наступний місяць після реєстрації?)
1  reg 2024-01     2024-02-03  ✓
2  reg 2024-02     лише лютий і квітень, березня нема ✗
3  reg 2024-03     2024-04-10  ✓
4  reg 2024-03     лише березень ✗
5  reg 2024-05     2024-06-02  ✓
6  reg 2024-06     логінів нема ✗

cohort    size  retained
2024-01   1     1
2024-02   1     0
2024-03   2     1
2024-05   1     1
2024-06   1     0
```

**Завдання:** для кожного місяця реєстрації: скільки зареєструвалось і скільки з них логінились у наступному місяці. Місяць як дата першого числа (`date_trunc('month', created_at)::date`). Порядок за `cohort`.

**Колонки:** `cohort, size, retained`

**Таблиці:** `users`, `logins`
