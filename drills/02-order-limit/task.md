# 02 · order by + limit

**Патерн:** спочатку сортування, потім `limit` ріже вже відсортований список. Якщо суми однакові, додай другу колонку для порядку.

```
order by amount desc, id

(id=7, 200)
(id=6, 200)   ← однакова сума, тому далі вирішує id
(id=1, 100)

після id=6 і id=7 порядок за id: 6 раніше за 7
```

**Завдання:** 3 найбільші оплачені (`paid`) замовлення. При однакових сумах першим іде менший `id`.

**Колонки:** `id, amount`

**Таблиця:** `orders`
