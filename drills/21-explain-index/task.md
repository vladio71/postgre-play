# 21 · EXPLAIN: індекс

**Патерн:** `explain` показує, як база виконає запит. `Seq Scan` це читання всієї таблиці. Індекс дозволяє піти одразу до потрібних рядків.

```
таблиця big_orders: 100 000 рядків, 1000 користувачів, по 100 замовлень на кожного

select * from big_orders where user_id = 777;     ← потрібно 100 рядків із 100 000

без індексу:  Seq Scan on big_orders   (прочитав усе)
з індексом:   Index Scan / Bitmap Index Scan (пішов до потрібних)
```

**Завдання:** у `my.sql` створи індекс, після якого план цього запиту більше не містить `Seq Scan`.

Перевірка покаже план до і після: `npm run check 21`

**Таблиця:** `big_orders`
