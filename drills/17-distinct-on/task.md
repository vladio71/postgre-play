# 17 · distinct on (Postgres): перший рядок групи

**Патерн:** `distinct on (колонка)` лишає по одному рядку на кожне значення колонки. Який саме, вирішує `order by` (він має починатися з тієї ж колонки). Це коротка альтернатива `row_number() ... where rn = 1`.

```
user_id | created_at          order by user_id, created_at
   1    | 02-10                 → для user 1 лишається 02-01
   1    | 02-01  ← лишається
   2    | 03-01  ← лишається
```

**Завдання:** перше (найраніше за `created_at`) замовлення кожного користувача. При однаковій даті менший `id`.

**Колонки:** `user_id, id`

**Таблиця:** `orders`
