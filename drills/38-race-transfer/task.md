# 38 · одночасні запити: переказ без втрати грошей

**Як перевіряється:** 2 з'єднання одночасно переказують по 80 з рахунку 1 на рахунок 2.

```
accounts: 1 → 100, 2 → 50   (разом 150)

два перекази по 80 одночасно:
  правильно:   перший пройшов (1: 20, 2: 130), другий відмовлено. Разом усе ще 150.
  неправильно: списання з умовою, а зарахування без умови → 2: 210. Гроші взялись нізвідки.
```

Два `update` треба зв'язати: зарахувати лише тоді, коли списання **справді** відбулось. У plain SQL це робить `with ... as (update ... returning ...)`: другий `update` дивиться, чи перший щось повернув.

```sql
with debit as (
  update ... returning id
)
update ... where exists (select 1 from debit);
```

**Завдання:** переказ 80 з рахунку 1 на рахунок 2 одним statement, так, щоб сума на двох рахунках ніколи не змінювалась.

**Таблиця:** `accounts`
