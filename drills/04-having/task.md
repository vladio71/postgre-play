# 04 · having

**Патерн:** `where` фільтрує **рядки до** групування, `having` фільтрує **групи після**.

```
where  status = 'paid'            → відсіяв рядки
group by user_id                  → зібрав групи
having sum(amount) > 100          → відсіяв групи

user 1: сума 170  → лишається
user 5: сума  45  → відпадає
```

**Завдання:** користувачі, у яких сума оплачених (`paid`) замовлень більша за 100.

**Колонки:** `user_id, total`

**Таблиця:** `orders`
