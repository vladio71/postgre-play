# 18 · lateral: цикл по рядках зліва

**Патерн:** `lateral` дозволяє підзапиту бачити рядок зліва. Це цикл: для кожного `u` виконай підзапит.

```
for u in users:
    взяти замовлення цього u
    відсортувати за amount desc, id
    лишити 2

cross join lateral        → users без замовлень зникають
left join lateral ... on true  → вони лишаються з null
```

**Завдання:** 2 найбільші замовлення кожного користувача (усі статуси, при однакових сумах менший `id` першим). Користувачі без замовлень теж мають бути в результаті, з порожніми полями.

**Колонки:** `email, order_id, amount`

**Таблиці:** `users`, `orders`

Потім порівняй зі своєю відповіддю з 14: результат той самий, а підхід інший.
