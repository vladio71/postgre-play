# 23 · lateral ще раз: останні 3 повідомлення кожного чату

**Патерн:** той самий `lateral`, що й у 18, але інший домен. Для кожного чату зліва підзапит справа бере **його** повідомлення, сортує і лишає 3.

```
for chat in chats:
    взяти messages цього chat
    відсортувати за sent_at desc
    лишити 3
```

Таблиці:

```
chats                messages
1 dev                1  chat 1  2024-06-01 09:00  standup at 10
2 sales              2  chat 1  2024-06-01 12:30  deploy done
3 random (порожній)  3  chat 1  2024-06-02 08:15  tests are red
                     4  chat 1  2024-06-02 09:40  fixed
                     5  chat 1  2024-06-02 09:41  thanks
                     6  chat 2  2024-06-01 10:00  q2 numbers?
                     7  chat 2  2024-06-01 10:05  sending today
```

**Завдання:** для кожного чату 3 останні повідомлення (найновіші першими). Чат `random` без повідомлень має лишитись у результаті з порожніми полями.

**Колонки:** `title, message_id, body`

**Таблиці:** `chats`, `messages`
