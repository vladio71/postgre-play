# 01 · select + where

**Патерн:** `where` лишає тільки рядки, що підходять під умову. Кілька умов з'єднуються через `and`.

```
status = 'paid' and amount >= 70

(paid, 100)  → лишається
(paid,  30)  → відпадає, замало
(cancelled, 200) → відпадає, не той статус
```

**Завдання:** оплачені (`paid`) замовлення на суму від 70 включно.

**Колонки:** `id, user_id, amount`

**Таблиця:** `orders`
