# 09 · union проти union all

**Патерн:** `union` прибирає дублі (і витрачає на це час). `union all` просто клеїть.

```
A: 1, 2, 2        B: 2, 3

union      → 1, 2, 3          (3 рядки)
union all  → 1, 2, 2, 2, 3    (5 рядків)
```

**Завдання:** одним запитом покажи два числа: скільки рядків дасть `union` і скільки `union all` над `user_id` з `orders` (усі замовлення, будь-який статус) та `reviews`.

**Колонки:** `union_rows, union_all_rows`

**Таблиці:** `orders`, `reviews`
