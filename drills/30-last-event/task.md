# 30 · distinct on проти row_number: останній статус замовлення

**Патерн:** "останній рядок на групу" це `rn = 1` (14) або `distinct on` (17). Тут ти вибираєш сам: обидва дають той самий результат.

```
order_events (order 4)
8   created    03-05 12:00
9   paid       03-05 12:01
10  shipped    03-06 08:00
11  delivered  03-09 17:20   ← останній
```

**Завдання:** поточний (останній за `at`) статус кожного замовлення з `order_events`. Зроби обома способами в `npm run play`, у `my.sql` лиши один.

**Колонки:** `order_id, status`

**Таблиця:** `order_events`
