# 13 · with (CTE): запит кроками

**Патерн:** `with` дає проміжному результату ім'я. Кроки йдуть ланцюжком, наступний бачить попередній.

```
with step1 as ( ... ),
     step2 as ( ... з step1 ... )
select ... from step2;
```

**Завдання:**

```
крок 1: сума оплачених (paid) замовлень на кожного користувача
крок 2: середнє по цих сумах
вивід : користувачі, чия сума вища за це середнє
```

**Колонки:** `user_id, total`

**Таблиця:** `orders`
