# 08 · union

**Патерн:** `union` ставить результати **один під одним** і прибирає дублі. Колонок і типів має бути однаково.

```
select user_id from A      A: 1, 2, 2
union                      B: 2, 3
select user_id from B
                           →  1, 2, 3   (дубль двійки зник)
```

**Завдання:** кому слати розсилку: користувачі, що мають оплачене (`paid`) замовлення **або** залишили відгук. Кожен один раз.

**Колонки:** `user_id`

**Таблиці:** `orders`, `reviews`
