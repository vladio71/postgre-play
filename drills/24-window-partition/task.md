# 24 · window по партиції: наростаючий підсумок усередині відділу

**Патерн:** у 16 було `sum() over (order by day)` по всій таблиці. Тут те саме, але **окремо в кожному відділі**: `partition by dept` ділить рядки на групи, `order by hired` задає порядок усередині групи.

```
eng, за датою найму:
  Taras  7000   running 7000    diff null      ← перший у відділі
  Vlad   5000   running 12000   diff -2000
  Max    5000   running 17000   diff 0
  Dasha  3500   running 20500   diff -1500

sales починається заново з running = salary першого
```

**Завдання:** для кожного співробітника: відділ, ім'я, зарплата, накопичена сума зарплат відділу на момент його найму (`running`) і різниця з зарплатою попереднього найнятого в тому ж відділі (`diff`, у першого `null`). Порядок: `dept`, потім `hired`.

**Колонки:** `dept, name, salary, running, diff`

**Таблиця:** `employees`
