# 20 · бос: усе разом

**Патерн:** join + group by + CTE + row_number в одному запиті.

```
крок 1: paid-сума на користувача, разом з його країною   (join + group by)
крок 2: у межах кожної країни пронумерувати за сумою      (row_number, partition by country)
крок 3: лишити номер 1
```

**Завдання:** для кожної країни користувач з найбільшою сумою оплачених (`paid`) замовлень. Країни, де ніхто нічого не оплатив, у результат не потрапляють.

**Колонки:** `country, email, total`

**Таблиці:** `users`, `orders`
